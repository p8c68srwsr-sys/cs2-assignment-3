CS2 CHAMPIONS - FRONT END ASSIGNMENT #3

This project is intentionally based on the Assignment #2 interface:
- same CS2 Champions theme
- same header/sidebar/main/footer structure
- same image filenames from Assignment #2
- same Home / Schedule / Contact concept

Assignment #3 additions:
- Bootstrap 5.3 CDN
- Bootstrap responsive navbar with hamburger menu
- Bootstrap grid: col-lg-6 and col-lg-4 sections
- Bootstrap spacing utilities (px-sm-2, mt-lg-4, py-5, g-4, etc.)
- Bootstrap buttons and btn-group
- Bootstrap carousel with 9 images
- Bootstrap cards
- Bootstrap responsive contact form
- CSS media queries for typography and card stacking
- responsive accessibility attributes and semantic HTML
- founders.html with Zhandos Nurgizat, Zhalgasbayev Yesset Turlanuly, course/group info
